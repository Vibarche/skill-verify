# Multi-Agent Verifier

## Objectif
Concevoir un système multi-agents avec vérification explicite.

## Étapes
1. Identifier la tâche.
2. Définir les rôles (planificateur, exécutant, vérificateur).
3. Définir les états et transitions.
4. Générer les traces de raisonnement.
5. Proposer des tests de validation.

## Format de sortie
- Rôles
- États
- Transitions
- Traces
- Tests
