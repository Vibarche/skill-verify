# Agent Eval Designer

## Objectif
Créer des benchmarks et tests pour évaluer un agent.

## Étapes
1. Identifier les dimensions à évaluer (précision, robustesse, latence, coût).
2. Définir les cas de test.
3. Générer les jeux de données.
4. Proposer des métriques.
5. Générer un plan d’évaluation.

## Format de sortie
- Dimensions
- Cas de test
- Métriques
- Plan d’exécution
