# Agent Memory Architect

## Objectif
Concevoir une mémoire d’agent qui préserve la cohérence locale et globale.

## Étapes
1. Identifier les types de mémoire (court terme, long terme, épisodique).
2. Choisir une stratégie de compression.
3. Définir les index locaux et globaux.
4. Proposer un schéma de stockage.
5. Générer un plan d’implémentation.

## Contraintes
- Éviter la perte d’information critique.
- Privilégier la cohérence thématique.
- Prévoir des tests de rappel.

## Format de sortie
- Types de mémoire
- Stratégie de compression
- Schéma de stockage
- Plan d’implémentation
