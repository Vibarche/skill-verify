# Agent Reliability Toolkit

Design, audit and harden AI agents with reusable reliability workflows.

This plugin groups skills related to agent memory architecture, multi-agent verification, evaluation, self-hosted deployment, skill design and MCP reliability.

## Install

```text
/plugin marketplace add agtktID/skill-verify
/plugin install agent-reliability-toolkit@skill-verify
```

## Skills

The plugin-local `skills/` directory is the installation boundary for this bundle. The canonical skill sources remain maintained in the repository-level `skills/` directory.
