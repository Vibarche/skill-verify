# Brain Management

Initialize and manage an agent brain.

This plugin exposes the following skills:

- `setup-brain`: initializes the brain and delegates skill operations to `skill-manager`.
- `skill-manager`: manages the skill lifecycle without modifying `AGENTS.md`, hubs or notes.

## Install

```text
/plugin marketplace add agtktID/skill-verify
/plugin install brain-management@skill-verify
```
