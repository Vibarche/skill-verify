# Project About template

Use this skeleton for every hub and project `About.md`. Fill only information supplied by the user; write `To fill` rather than inventing a fact, number or link.

```markdown
---
status: active   # active | paused | done
updated: YYYY-MM-DD
---

# Project name

One paragraph describing what this is and its goal.

## Key info

- Links, identifiers, accounts and local paths

## Current state

- Completed work
- Next work

## Decisions

- YYYY-MM-DD: Decision, because reason.
- YYYY-MM-DD: Rejected option, because reason.
```

Omit `## Decisions` until there is a real decision. When adding one, always include the reason and, where relevant, the rejected alternative.
